# AddRayBCAction

!syntax description /RayBCs/AddRayBCAction

For more information, see [RayBCs/index.md].

A [RayBCs/index.md](RayBC) requires a [RayTracingStudy.md] to be associated with it. This is provided with the `study` parameter. If the `study` parameter not provided, the associated [RayTracingStudy.md] will be the one study object that exists. If multiple studies exist, the `study` parameter must be provided.

!syntax parameters /RayBCs/AddRayBCAction
